# ✈️ Planora — AI Trip Planner

Planora is an AI-powered travel planning website designed to simplify the process of organizing trips. It provides a digital space for users to explore travel destinations and plan itineraries based on their travel preferences.

The project combines a modern web interface with AI-assisted planning to make travel organization more convenient.

## ✨ Features

- 🌍 Travel destination exploration
- 🗺️ Trip planning interface
- 🧠 AI-assisted itinerary generation, if configured
- 📅 Travel schedule organization
- 🎨 Modern and responsive user interface
- 🧳 Personalized travel planning workflow
